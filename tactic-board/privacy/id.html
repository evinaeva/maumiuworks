Tacticana — Kebijakan Privasi

Tacticana tidak mengumpulkan, membagikan, atau menjual data pribadi apa pun. Satu-satunya yang dikirim adalah hitungan penggunaan anonim (lihat di bawah), dan Anda bisa mematikannya.

  • Berjalan offline. Semuanya berfungsi tanpa koneksi internet. Satu-satunya yang dikirim aplikasi adalah statistik penggunaan anonim yang dijelaskan di bawah, dan Anda bisa mematikannya. Aplikasi juga dapat mengunduh pembaruan teks dan tabelnya (lihat "Pembaruan data" di bawah).
  • Tanpa akun, tanpa iklan. Tidak ada login, SDK iklan, SDK analitik atau laporan kerusakan pihak ketiga, dan ID iklan.
  • Statistik penggunaan anonim. Untuk mengetahui bagian aplikasi mana yang berguna, aplikasi menghitung di ponsel Anda, per hari, layar mana yang dibuka, layar mana yang terbuka saat Anda keluar dari aplikasi, tombol utama mana yang ditekan, dan fungsi mana (misalnya ekspor) yang dipakai. Sekali sehari, aplikasi mengirim hitungan ini ke server kami sendiri (stats.jevgenia.com) bersama versi aplikasi, bahasa aplikasi, dan tanggal. Tidak ada ID perangkat atau ID iklan, ID sesi, waktu persis, lokasi, atau apa pun yang Anda ketik yang dikirim. Server hanya menambahkan hitungan ke total harian per versi dan tidak menyimpan permintaannya. Seperti setiap permintaan internet, server melihat alamat IP Anda; server memakainya hanya di memori untuk menerima permintaan dan membatasi penyalahgunaan, dan tidak pernah menyimpan atau mencatatnya. Total disimpan paling lama 25 bulan dan tidak dibagikan kepada siapa pun. Anda bisa mematikannya kapan saja di Setelan («Kirim statistik penggunaan anonim»); hitungan yang belum terkirim akan dihapus. Dasar hukum: kepentingan sah kami untuk memperbaiki aplikasi (Pasal 6(1)(f) GDPR); datanya anonim.
  • Data Anda tetap di ponsel. Papan, folder, skuad (nama dan nomor pemain), dan pengaturan Anda hanya disimpan di penyimpanan pribadi aplikasi di perangkat Anda. Data tersebut terhapus saat Anda meng-uninstal aplikasi atau menghapus datanya.
  • Cadangan dan file ekspor milik Anda. Jika Anda menyimpan cadangan atau mengekspor papan (file papan, gambar, animasi GIF, video MP4, atau PDF), file hanya dikirim ke tempat yang Anda pilih: aplikasi yang Anda pilih di menu “Bagikan” atau folder pilihan Anda. Di Android 10 dan yang lebih baru, Anda juga bisa meminta aplikasi menyimpan gambar atau video ke Galeri ponsel (album Tacticana). Aplikasi tidak mengirim file tersebut ke tempat lain.
  • Pencadangan sistem Android. Jika Anda mengaktifkan pencadangan bawaan Android, Android dapat menyertakan data aplikasi dalam cadangan pribadi perangkat Anda di Akun Google Anda. Hal ini Anda atur sendiri di setelan ponsel, bukan oleh aplikasi.
  • Google Play. Aplikasi ini didistribusikan melalui Google Play. Google dapat meminta Anda memberi nilai aplikasi atau menawarkan pembaruan melalui layar sistemnya sendiri; semuanya ditangani oleh Google Play sesuai kebijakan privasi Google.
  • Anak-anak. Aplikasi ini tidak ditujukan untuk anak-anak dan tidak dengan sengaja mengumpulkan data pribadi dari siapa pun.
  • Pembaruan data. Aplikasi dapat mengunduh teks dan tabel referensi yang diperbarui dari server kami (capgo.jevgenia.com). Permintaan tersebut tidak berisi pengenal apa pun tentang Anda atau perangkat Anda; seperti permintaan internet lainnya, permintaan ini memperlihatkan alamat IP Anda kepada server, yang hanya menggunakannya untuk mengirim file dan tidak menyimpannya.

Perubahan kebijakan ini dipublikasikan di halaman ini dengan tanggal baru. Pertanyaan: hello@maumiuworks.com.
